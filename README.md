# CGLI

Interface visual de orquestração de agentes de IA em tela infinita (estilo n8n).

## Conceito
- **Canvas Infinito**: Navegação livre (pan/zoom) com nós conectáveis.
- **Nós de Agentes / Terminais**: Instâncias interativas de agentes CLI como Claude Code e AGY (Antigravity).
- **Orquestração de Fluxos**: Pipeline visual para passagem de contexto, paralelismo e supervisão de agentes autônomos.
